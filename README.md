# Esquadrão Antibomba

Jogo de memorização de Microbiologia para alunos do técnico de enfermagem. Funciona no celular, sem cadastro, e sem internet depois do primeiro acesso.

- `src/banco.js`: questões, com a página do slide de origem, e os pontos a revisar com a professora
- `src/figuras.js`: personagens e diagramas em SVG
- `node build.js`: confere o banco e gera o `index.html`
- `python testar.py`: joga todas as questões em tela de celular (requer Playwright)
